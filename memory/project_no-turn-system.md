ターン制は不要。ゲームはUndertaleのターン制ではなく、敵の攻撃をよけ続ける弾幕ゲーム。

**Why:** ユーザーが明確にターンマネージャー・メニューを不要と判断。
**How to apply:** ターン制UIやメニュー選択の提案をしない。敵の弾幕パターンが連続的に発生する設計で進める。
